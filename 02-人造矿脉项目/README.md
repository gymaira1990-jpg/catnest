## 核心理论

- **加速人工成岩（Accelerated Artificial Diagenesis, AAD）**：将地质尺度的自然成岩作用通过多因素协同强化，压缩至 5 年工程尺度
- **"酱缸计划"**：多源固废（钢渣+有机废弃物+微生物+昆虫）协同转化生态系统
- **"人造矿脉"范式**：从"环境负债"到"资源资产"的根本性转换

## 关键机制

- 微生物诱导碳酸钙沉淀（MICP）
- 有机酸-钙离子释放耦合
- 钢渣自粉化主动利用
- 生物产热-自热维持耦合
- CO₂原位供给-碳化耦合
- 黑水虻生物转化
