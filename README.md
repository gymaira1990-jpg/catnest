## 🌌 我们为什么在这里

当前的主流 AI，正陷入一场"大力出奇迹"的军备竞赛。大厂们不断堆砌参数、烧钱训练、用昂贵的上下文窗口吞噬一切。

但对于我们——普通的用户、开发者、个人——这是一条不可持续的道路。

**我们坚信，个人 AI 的未来，不在于一个全知全能的超级大脑，而在于一群运行在本地、专精高效、能自我管理和持续进化的"小脑集群"。**

**Cerebella** 正是为此而生。它不是一个模型，而是一个**生态**。一个能将你的个人电脑，从一个被动的 AI 客户端，转变为一个主动的、自我成长的 AI 执行中枢的完整方案。

## 🧬 核心哲学：为什么是"小脑"，而不是"大脑"？

大模型普遍存在"灾难性遗忘"——当你教它新东西时，它可能会忘掉旧知识。

我们的解法是：**不把所有东西都塞进一个脑子里。**

### Cerebella 模拟了人脑的分区结构

| 组件 | 角色 | 类比 |
|------|------|------|
| 🗣️ **路由脑** | 语言中枢 (0.5B) | 判断闲聊还是干活，分发任务 |
| 🧠 **专业脑** | 技能中枢 | 每个只干一件事，独立成长互不干扰 |
| 🤖 **项目脑** | 管理中枢 | 永远在线的项目经理 |

### 核心优势

- 🔋 **资源极省** — CPU 默认模式，0 显存占用，打 3A 大作时也在后台安静工作
- 🌱 **成长可续** — 每个小脑独立学习，彻底解决灾难性遗忘
- 🧩 **按需扩展** — 插入"技能卡"，系统能力自动扩展。无限小脑插拔，无限能力生长

## 🔄 重新定义交互：聊天是沟通，文件是契约

我们不只重新设计了 AI 的大脑，更重新定义了人与 AI 的协作方式：

- 💬 **聊天通道** — 即时、灵活。闲聊、催促、口头下达模糊需求。**但聊天记录不作为最终的执行依据。**
- 📄 **文件通道** — 确定、权威。真正的任务必须写入**任务书**文件，AI 集群在执行层面**只认任务书**。

**一份任务书，就是一个项目驾驶舱。** 它既是需求文档，也是进度表，更是最终的状态标记。你可以在一个文件夹里管理整个 AI 团队——无需专用 APP，管理文件夹就是管理你的 AI 公司。

## 🧠 四层记忆体系：彻底告别昂贵的上下文窗口

传统大模型的上下文窗口是一个昂贵且低效的妥协方案。Cerebella 用四个精准的替代方案彻底解决：

1. 🔥 **燃烧层** — 闲聊、情绪表达，直接"燃烧"，不进入任何记忆系统
2. 🗜️ **压缩层** — 工作指令实时压缩成结构化任务描述，剔除所有语言噪声
3. 📇 **指针层** — Agent 只保存"我做过什么"的摘要和索引指针
4. 🧠 **内化层** — 高频知识和技能最终内化到模型参数，零检索延迟

### 记忆仓库四级体系

| 层级 | 存储 | 速度 | 生命周期 |
|------|------|------|----------|
| 🔥 热记忆 | 向量库 | 毫秒级 | 本周高频 / 当前项目 |
| 🌡️ 温记忆 | 文件系统+索引 | 秒级 | 近期完成常用经验 |
| ❄️ 冷记忆 | 压缩归档 | 按需 | 封存项目文档 |
| 🗑️ 遗忘区 | — | 自动清理 | 过时、低价值信息 |

**知识不会丢失，也不会无限膨胀。**

## 🏗️ 专业技术架构

### 整合现有技术（拿来主义）

- **意图路由** — 基于 ClawRouter / Semantic Router，毫秒级本地意图分类
- **大小模型协同** — Stanford Minions 协议，小模型起草、大模型审阅，节省 80% 云端 Token
- **推理与微调** — Ollama + Unsloth，本地高效推理和微调
- **记忆仓库** — 跨 AI 工具的通用本地记忆

### 核心研发模块（护城河）

- 🔌 **多脑注册与调度总线** — 统一管理 N 个独立微调小模型的注册、发现与调用
- 🎴 **技能卡 (Skill Card) 系统** — 标准化模型打包、分发、加载
- 🔄 **三阶段渐进式内化引擎** — 从索引知识 → 调度知识 → 内化知识，自动进化
- 📊 **项目脑 (Project Brain)** — 基于文件状态机的项目监控自动化管理

### 硬件适应

| 模式 | 占用 | 场景 |
|------|------|------|
| 💻 **默认 (CPU)** | 2-4 线程，0 显存 | 游戏、日常办公 |
| ⚡ **高性能 (GPU)** | 全 GPU 吞吐 | 专用机 |
| 🔮 **未来 (NPU)** | 零 CPU/GPU 占用 | Intel/AMD NPU |
