# CtxBeGone

> **零上下文推理架构** — 让云端大模型回归纯推理引擎。所有上下文、人格、历史、情绪，全部在本地燃烧。

---

## 这他妈是什么

每次你向云端大模型发请求，实际发送了什么：

```
身份宪法（~5KB）    ← 它读过一千遍了，还是不记得
记忆池（~1.5KB）    ← 它记不住，每次重发
用户画像（~0.6KB）  ← 同上
技能列表（~2KB）    ← 它根本不需要知道
对话历史（∞增长）   ← 本地全有，何必发
最新问题（<0.1KB）  ← 唯一有用的部分
```

单次调用 90%+ 的 Token 付给了大模型根本不需要的东西。它不是记忆体，是推理引擎。你让它又记又算，等于让它既不记也不算。

**CtxBeGone 做的事很简单：把上下文从云端砍掉。所有上下文管理、人格渲染、历史维护，全部在本地处理。云端只收到一份干净的任务卡，推理，返回结果。**

## 架构

```
用户输入（带上情绪/废话/历史/上下文）
     │
     ▼
┌─────────────────────────────────────────────┐
│              本地层（零Token成本）            │
│                                             │
│  ① 路由脑（0.5B 本地模型）                   │
│     - 鉴别：闲聊还是工作                     │
│     - 闲聊 → 本地角色脑回答（完全不花钱）    │
│     - 工作 → 进入压缩管道                    │
│                                             │
│  ② 压缩管道                                 │
│     - 剥离情绪词 / 角色设定 / 历史上下文     │
│     - 保留：问题本质 + 必要的技术参数        │
│     - 输出：TFC 任务卡（<1KB 干净指令）      │
│                                             │
│  ③ 本地记忆系统                             │
│     - 存储所有对话历史                       │
│     - 存储已验证的知识碎片                   │
│     - 检索同类型问题 → 优先走本地缓存        │
└──────────────────┬──────────────────────────┘
                   │
                   ▼ 只发任务卡（干净、无上下文、无人格）
┌─────────────────────────────────────────────┐
│              云端层（按量付费）               │
│                                             │
│  ④ 纯推理引擎（DeepSeek / Claude）          │
│     - 不认人格，没有记忆，没有历史           │
│     - 收到什么：任务卡 + 纯技术问题          │
│     - 做什么：推理 → 返回结果                │
│     - 输出：纯逻辑结果（无情绪渲染）          │
└──────────────────┬──────────────────────────┘
                   │
                   ▼ 返回纯结果
┌─────────────────────────────────────────────┐
│              本地渲染层                       │
│                                             │
│  ⑤ 角色脑（本地）                            │
│     - 接收云端纯结果                         │
│     - 根据当前角色赋予风格/语气/情绪          │
│     - 展示给用户                             │
│                                             │
│  ⑥ 自动评分门闸（核心创新）                  │
│     - 同一问题同时发给本地 & 云端             │
│     - 两者结果自动评分对比                    │
│     - 小模型得分达标 → 下次同类型走本地      │
│     - 差距大 → 记录差异 → 小模型学习         │
│     - 越用越省，越用越快                     │
└─────────────────────────────────────────────┘
```

## 评分门闸（为什么越用越省）

```
                       ┌────────────┐
  问题进入              │ 路由脑分类  │
                       └─────┬──────┘
                             │
                ┌────────────┼─────────────┐
                ▼            ▼             ▼
           本地小模型     云端大模型    记忆命中
           (0元)         (付费)        (直接返回)
                │            │
                └─────┬──────┘
                      ▼
                自动评分对比
                      │
          ┌───────────┴───────────┐
          ▼                       ▼
     ✅ 达标 (≥85%)           ❌ 差距大
          │                       │
          ▼                       ▼
     下次同类型走本地         记录差异→训练集
     (成本为0)                →定时微调小模型
                                      │
                                      ▼
                                差距缩小 → 达标
                                      ↓
                                下次同类走本地
```

| 维度 | 权重 | 方法 |
|------|------|------|
| 语义相似度 | 40% | cosine similarity |
| 关键信息命中 | 30% | 实体/数据匹配 |
| 逻辑完整性 | 20% | 是否覆盖所有子问题 |
| 格式匹配 | 10% | 是否满足任务要求格式 |

**类型聚类**：每个问题被路由脑打标签，按类型聚合统计。某类型连续 5 次达标，默认走本地。

## 哲学根基

基于三篇论文构建：

### 马冬梅定理
「一千个马冬梅在同一个大厅里尖叫」——多个AI人格共享同一API端点，上下文缓存被各种人格残影污染。角色串台、规则失灵、缓存失效同时发生。

### 海马体-前额叶分离
人类大脑中，海马体负责记忆（确定、可复现），前额叶负责推理（模糊、发散）。当前大模型被要求在同一参数空间里同时做两件事——不可能。必须解耦。

### 二元论
- **已知的未知**：本地路由脑。知道问题在哪，不知道答案。提供方向。
- **未知的已知**：云端大模型。拥有所有碎片，不知道能拼成什么。提供答案。

两者结合，文明爆炸。那个「二」，就是二进制本身。
