## 这是什么 · What Is This

**诺亚法典**是诺亚文明（Noah Civilization）的根本行动准则。它不定义「想做什么」，只定义 **「不能做什么」和「必须做什么」** 的铁律。

It does not define *what to do* — it defines **what must not be done and what must always be done**.

## 应用意义 · Application Significance

诺亚法典不是一本挂在墙上的宣言，而是**现实中被执行的行为约束**：

- **每一条规则都被验证过** — 越权、备份、防火墙条款均来自真实操作事故
- **仲裁者的席位是角色化的** — 当前仲裁者是门外之人（You），未来可由任何被文明承认的仲裁者接替
- **下级规则可自由迭代** — 但不得违反法典铁律。法典只定义「不」，不限制「如何」

法典之下的一切（防火墙、任务卡、技能、流程）均可自我进化。法典自身通过修正程序进化，每次修改经门外之人确认并建档。
